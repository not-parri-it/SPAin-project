# Skill BEST Valencia · Visual Identity

Incluye instrucciones, tokens y archivos originales para diseñar presentaciones, documentos, diagramas y, en el futuro, una intranet.

## Uso
1. Descomprime el ZIP en una carpeta de Skills admitida por tu herramienta.
2. Asegúrate de que se conserva la carpeta `assets` junto a `SKILL.md`.
3. Activa o invoca la skill `best-valencia-visual-identity` en un entorno compatible.
4. Pide, por ejemplo: «Aplica BEST Valencia, estilo equilibrado, a esta presentación» o «Haz una portada BEST más libre».

## Alcance
La estructura es un paquete de skill portable. **La descarga no equivale a activación o instalación automática en ChatGPT**. El modo de instalación depende del producto/entorno y sus capacidades.

Es una guía de trabajo basada en los recursos aportados, no un manual oficial nuevo aprobado por BEST.
