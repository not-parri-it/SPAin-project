Añadir miembro

Nombre, apellidos y estatus son obligatorios en el alta.

Cada miembro recibe un ID técnico que permanece estable.

Registrar cambio de estatus

Esta operación crea un registro histórico y actualiza Miembros.

Atención: Inactive. Tras guardar este cambio, revisa si hay que marcar manualmente al miembro para borrado. El sistema no lo hará automáticamente.
Este cambio quedará registrado en la hoja «Cambios de estatus» y en la columna «Estatus» de «Miembros». No sirve para corregir masivamente el histórico.

Marcar cambio para borrado

El registro seguirá existiendo en la hoja histórica, pero dejará de aparecer en la aplicación.

Importante: esta acción no deshace el cambio de estatus ni modifica la hoja Miembros. Para corregir el estatus actual, usa el flujo de cambios de estatus.

Marcar para borrado

El miembro dejará de aparecer en el listado habitual, pero sus datos se conservan.
